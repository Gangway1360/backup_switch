📂 Configs

Catalogue matériel

Les configs ne contiennent pas toujours le modèle exact, le nombre de ports ni le PoE. Ce catalogue (enregistré dans ton navigateur) complète l'analyse.
models : par référence produit (ex. JL256A) → { "name": "…", "ports": 48, "poe": true }.
rules : par expression régulière sur le hostname et/ou le chemin du fichier ("on": "host" | "file", sinon les deux) → { "match": "^SW-IDF", "name": "OS6860E-P48", "ports": 48, "poe": true }.
